# SpringCollab2020

SpringCollab2020 port for the Shared runtime. Workspace location: `Mods/SpringCollab2020/`.

Projects:

- `Celeste.Mods.SpringCollab2020.csproj`

Repository dependencies: **Shared**. Prepare Shared resources using the [Tools README][tools-readme], then build the main project:

```powershell
dotnet build ./Mods/SpringCollab2020/Celeste.Mods.SpringCollab2020.csproj -c Release
```
